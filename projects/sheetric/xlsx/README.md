# XLSX

Sheetric의 기존 기능정의서 XLSX를 보관하는 폴더입니다.

## 무엇에 쓰나요?

AI가 `/spec-flow`, `/project-flow`를 실행할 때 기존 기능정의서를 참고합니다.

주로 아래를 확인합니다.

- 기존 기능 ID
- 기존 L10N ID
- 기존 QA 기준
- 이미 정의된 화면과 섹션
- 새 요구사항과 충돌할 수 있는 기존 정책

## 사람이 볼 때

상세 동작이 궁금하면 이 폴더의 XLSX를 확인하면 됩니다.

단, 확정된 방향이나 정책을 찾을 때는 먼저 `decisions/`를 보고, 기능이 어디에 있는지 알고 싶을 때는 `features/feature-index.md`를 봅니다.

## 주의할 점

- 오래된 XLSX라도 AI가 기존 ID 충돌을 확인하는 데 사용할 수 있습니다.
- XLSX를 교체할 때는 같은 폴더에 최신 기준 파일을 올립니다.
- 임시 테스트 산출물은 이 폴더에 남기지 않습니다.

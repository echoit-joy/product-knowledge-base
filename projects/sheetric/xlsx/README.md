# XLSX

Sheetric의 현재 기준 기능정의서 XLSX를 보관하는 폴더입니다.

## 무엇에 쓰나요?

AI가 `/spec-flow`, `/project-flow`를 실행할 때 현재 기능정의서를 참고합니다.

주로 아래를 확인합니다.

- 기능 ID
- L10N ID
- QA 기준
- 이미 정의된 화면과 섹션
- 새 요구사항과 충돌할 수 있는 현재 정책

## 사람이 볼 때

상세 동작이 궁금하면 이 폴더의 XLSX를 확인하면 됩니다.

단, 확정된 방향이나 정책을 찾을 때는 먼저 `decisions/`를 보고, 기능이 어디에 있는지 알고 싶을 때는 `features/feature-index.md`를 봅니다.

## 주의할 점

- 이 폴더에는 최신 기준 XLSX 한 개만 유지합니다.
- 이전 버전은 별도 파일로 남기지 않고 Git 이력에서 확인합니다.
- 현재 파일의 2차 기능정의 버전은 `0.0.2`이며, `기능정의_2-1차`와 `기능정의_2-2차` 시트를 포함합니다.
- 임시 테스트 산출물은 이 폴더에 남기지 않습니다.

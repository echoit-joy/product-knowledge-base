# Sheetric Project Context

_updated: 2026-08-25_

## 현재 기준

- 기능정의서 정본: `xlsx/Sheetric 프로젝트.xlsx`
- 2차 기능정의 버전: `0.0.2`
- 2차 상세 시트: `기능정의_2-1차`, `기능정의_2-2차`
- L10N 기준 시트: `L10N`
- 기능 위치 색인: `features/feature-index.md`
- 확정 정책: `decisions/`

## 2차 주요 범위

- 노트·폴더 공유, 공유 드라이브, 공개·비공개 링크, 공유 그룹, 소유권 이전
- Altio 녹음, 문서 컨텍스트, AI 검색 설정과 읽기 전용 출처 열람
- 파일·폴더 업로드, 파일 미리보기, Markdown 노트 편집
- 워크스페이스, 칸반 보드, 카드 상세, 댓글
- 내 드라이브 아카이브
- Altio 프로젝트·대화 관리

## 문서 우선순위

1. `decisions/`의 상태가 `확정`인 문서
2. 최신 XLSX 기능정의서와 L10N
3. `features/feature-index.md`
4. `meetings/`의 회의 맥락

상태가 `대체됨` 또는 `삭제`인 decision과 현재 기능정의서가 충돌하면 현재 확정 decision 및 최신 기능정의서를 따른다. 회의록의 후보·초안은 현재 기능 범위로 직접 사용하지 않는다.

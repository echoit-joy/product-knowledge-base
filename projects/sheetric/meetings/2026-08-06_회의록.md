# 2026-08-06 회의록

## 목적

Sheetric 타부서 피드백과 2차 기능 추가/수정 후보를 기록한다.

이 문서는 회의록이며, 확정 기능정의서나 decision 문서가 아니다. 아래 후보는 아직 확정되지 않았으므로 `features/`, `decisions/`에는 바로 반영하지 않는다. 확정된 항목은 이후 별도 기능정의서 또는 decision 문서로 승격한다.

## 타부서 피드백

### 사용 가이드 필요

- 가이드 문서가 필요하다는 피드백이 있었다.
- 현재는 사용자가 어떻게 써야 할지 감을 잡기 어렵고, 무엇을 해야 하는지 모르겠다는 의견이 있었다.
- 발언자: 김동건 책임

### 차별성 인식 부족

- 비슷한 서비스나 기능이 많은데 Sheetric을 굳이 써야 하는 이유가 명확하지 않다는 피드백이 있었다.
- 발언자: 다수
- 후속 논의 방향:
  - AI 기능 강화 필요성 검토
  - 기존 유사 도구 대비 Sheetric의 핵심 차별점 정리
  - 신규 사용자 온보딩과 사용 예시 보강

## 2차 기능 추가/수정 후보

아래 항목은 확정 목록이 아니라 회의 중 나온 후보 목록이다.

### 공유와 권한

- 공유된 문서 보기 제한
- 노트/폴더 공유 및 공유 드라이브 기능
- 권한 설정
- 문서 검색 권한 설정
  - 도메인, 그룹 등 기준 검토
- 특정 버전 링크 공유
- 공유받은 문서 사본 저장
- 공유 대상 그룹핑
- 링크 액세스 권한 설정

### AI와 Altio

- 첨부 문서 요약
  - 서술형 요약 요청 가능
  - 목록형 요약 요청 가능
  - "목록형으로 바꿔줘" 등 후처리 명령 가능
- Altio 노트/폴더 대상 표시 기능
  - 노트/폴더 선택 시 입력창 상단에 첨부 카드 또는 chip 형태로 표시
- Altio 파일 태그
  - `@` 기반 파일 태그 검토
- 문서 컨텍스트 범위 정의
  - 현재 문서만 검색 대상으로 할지 검토
  - 이전에 열람한 문서까지 검색 대상으로 포함할지 검토
- Altio 메뉴 추가
  - 전체화면에서 대화 가능하도록 검토
- 외부 AI 서비스와 대화 컨텍스트 연계

### 문서와 노트 편집

- 표 생성 후 cell 위에 hover 시 `클립보드에 복사` 아이콘 노출
  - 표 내용을 쉽게 복사할 수 있도록 개선
- 엑셀 셀 복사 시 표로 작성되는 동작을 텍스트로 작성되도록 변경
- Markdown 파일 업로드 시 노트 뷰 제공
- 수정일 표시 형식 변경
  - 날짜 형식에서 시간 + 날짜 표시로 변경

### 탐색과 파일 관리

- 사이드바 파일/폴더 순서 변경
- 폴더 트리 드래그앤드랍
- 트리뷰에서 복수 선택 가능
- 파일 업로드

### 보드와 생산성

- Trello 기능
  - 칸반보드 형태 검토
- 단축키 변경
  - `Shift + 1/2/3` 검토
  - Altio 대화에서 `!`, `@`, `#` 입력이 불가능한 문제와 함께 검토

## 추가 논의 필요

- 2차 기능 후보 중 실제 포함 범위와 우선순위 결정
- 타부서 피드백을 반영한 사용자 가이드 문서 범위 결정
- Sheetric의 AI 차별화 방향 정의
- Altio가 참조할 수 있는 문서 컨텍스트 범위와 개인정보/권한 정책 검토
- 공유, 링크, 검색 권한 정책 간 충돌 여부 검토
- 파일 업로드, Markdown 업로드, 외부 AI 연계의 보안 정책 검토
- 단축키 변경 시 기존 브라우저/OS/편집기 단축키와 충돌 여부 확인

## 다음 액션 후보

- 사용자 가이드 초안 작성 여부 결정
- 2차 기능 후보를 기능군별로 분류하고 우선순위 산정
- AI 강화 방향을 별도 기획 논의 안건으로 분리
- 확정된 항목만 기능정의서 또는 decision 문서로 승격

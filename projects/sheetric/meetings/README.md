# Meetings

Sheetric 회의록과 논의 기록을 모아 두는 폴더입니다.

## 어떤 내용을 넣나요?

- 회의에서 나온 요구사항
- 아직 확정되지 않은 논의
- 다음에 다시 봐야 할 질문
- 기능 후보와 우려사항
- 결정으로 승격하기 전의 맥락

## decisions와 차이

회의록은 확정 결정이 아닙니다.

회의록에 적힌 내용은 AI가 참고할 수 있지만, 반드시 따라야 하는 기준은 아닙니다. 확정된 정책이 되면 `decisions/`에 별도 decision 문서로 정리합니다.

## 작성 팁

- 날짜와 핵심 키워드가 드러나는 파일명을 씁니다.
- 확정된 것과 논의가 필요한 것을 분리해 적습니다.
- 다음 액션이 있으면 마지막에 따로 적습니다.

예시:

- `2026-07-14_노트공유.md`

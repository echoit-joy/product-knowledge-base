# 모바일 업로드 페이지 및 업로드 범위

## 상태
추가

## 날짜
2026-09-16

## 프로젝트
- Sheetric

## 결정
- 모바일에서는 업로드를 모달이 아니라 별도 업로드 페이지로 제공한다.
- 모바일 사이드바에는 `업로드` 메뉴를 제공하고, 해당 메뉴를 선택하면 업로드 페이지로 진입한다.
- 모바일에서 파일 업로드 진입 시 동일한 업로드 페이지를 사용한다.
- 모바일 새로 만들기 흐름에서는 `폴더 업로드`를 제공하지 않고, 파일 업로드만 제공한다.
- 업로드 페이지 하단에는 `목록 비우기` 버튼을 제공한다.
- `목록 비우기`를 실행하면 현재 업로드 목록을 비운다.

## 이유
- 모바일 화면에서는 업로드 모달보다 별도 페이지가 목록 확인과 조작에 적합하다.
- 모바일에서는 폴더 업로드를 제공하지 않아 업로드 범위와 사용 가능 액션을 명확히 한다.

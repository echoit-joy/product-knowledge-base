# 내 드라이브 Ctrl+C·Ctrl+V 복사 지원

## 상태
추가

## 날짜
2026-09-03

## 프로젝트
- Sheetric

## 결정
- 내 드라이브 화면에서 폴더 트리 또는 테이블의 파일·폴더를 선택한 상태로 Ctrl+C 이후 Ctrl+V를 입력하면 선택한 항목의 사본을 생성한다.
- 생성되는 사본은 기존 우클릭 `복사하기` 메뉴와 동일한 정책을 적용한다.

## 이유
- 단축키로 복사 흐름을 제공하면 우클릭 메뉴를 거치지 않고도 Windows 탐색기·Google Drive와 유사한 방식으로 복사할 수 있다.
- 사본 생성 정책을 기존 `복사하기`와 통일해 두 진입 경로 간 동작 차이를 없앤다.

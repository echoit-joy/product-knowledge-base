# 노트 블록 드래그 선택

## 상태
수정

## 날짜
2026-07-22, 2026-09-16

## 프로젝트
- Sheetric

## 결정
- 노트 화면에서도 리스트형 페이지와 동일하게 드래그 중인 선택 영역을 시각적으로 표시한다.
- 드래그한 범위 안에 포함된 블록은 선택 상태가 된다.
- 선택 영역은 사용자가 어떤 블록이 선택 대상인지 예측할 수 있을 만큼 명확하게 표시한다.
- 블록을 드래그한 상태로 화면 상단이나 하단 영역에 접근하면, 드래그 상태를 유지한 채 노트 화면이 자동 스크롤되어야 한다.
- 사용자가 스크롤하면서 드래그 선택을 계속하면 스크롤된 영역의 블록까지 선택 범위를 자연스럽게 확장한다.
- 여러 블록을 선택한 상태에서 `전환`, `색`, `삭제`를 실행하면 선택된 모든 블록에 일괄 적용한다.
- 텍스트와 Altio 녹음 요약 블록 등 서로 다른 블록 유형이 함께 선택된 경우에도 복사, 붙여넣기, Delete/Backspace 삭제는 선택 범위 전체에 적용한다.

## 이유
- 노트 안에서 여러 블록을 선택할 때 선택 범위가 보이지 않으면 사용자가 선택 결과를 예측하기 어렵다.
- 드래그 범위와 실제 선택된 블록이 일치해야 다중 블록 편집 흐름이 안정적으로 동작한다.
- 선택 후 실행하는 편집 명령은 선택된 일부가 아니라 전체 범위를 대상으로 해야 사용자가 다중 선택의 결과를 예측할 수 있다.

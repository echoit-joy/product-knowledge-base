# 노트 블록 드래그 선택

## 상태
추가

## 날짜
2026-07-22

## 프로젝트
- Sheetric

## 결정
- 노트 화면에서도 리스트형 페이지와 동일하게 드래그 중인 선택 영역을 시각적으로 표시한다.
- 드래그한 범위 안에 포함된 블록은 선택 상태가 된다.
- 선택 영역은 사용자가 어떤 블록이 선택 대상인지 예측할 수 있을 만큼 명확하게 표시한다.

## 이유
- 노트 안에서 여러 블록을 선택할 때 선택 범위가 보이지 않으면 사용자가 선택 결과를 예측하기 어렵다.
- 드래그 범위와 실제 선택된 블록이 일치해야 다중 블록 편집 흐름이 안정적으로 동작한다.

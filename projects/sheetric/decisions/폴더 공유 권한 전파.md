# 폴더 공유 권한 전파

## 상태
확정

## 날짜
2026-07-14

## 프로젝트
- Sheetric

## 결정
- 폴더 공유 시 기존 하위 폴더와 노트 및 이후 생성되는 하위 항목에 동일한 접근 권한을 부여한다.
- 하위 항목에서 폴더 공유로 포함된 사용자를 삭제하면 해당 항목에서만 접근 권한을 제외한다.
- 상위 폴더에서 사용자를 삭제하면 해당 폴더의 모든 하위 폴더와 노트에서도 접근 권한을 제거한다.
- 하위 항목의 개별 제외 상태는 이후 새로 생성되는 하위 항목에 승계하지 않는다.
- 삭제된 사용자는 동일 항목에 다시 초대할 수 있다.
- 동일 사용자가 여러 공유 경로로 포함되어도 공유 대상 리스트에는 한 번만 표시한다.

## 이유
- 폴더 단위 공유의 일관성을 유지하면서 특정 하위 항목만 예외 처리할 수 있어야 한다.
- 상위 권한 변경과 신규 하위 항목 생성 시 적용 범위를 명확히 해야 한다.

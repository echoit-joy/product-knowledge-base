# 파일 업로드 다운로드 및 파일 상태 기준

## 상태
수정

## 날짜
2026-09-11

## 프로젝트
- Sheetric

## 결정
- 노트 안에 업로드된 일반 파일은 클릭하면 다운로드한다. 이미지, 오디오, 동영상은 기존 미리보기 또는 재생 동작을 유지한다.
- 공유 모드에서도 첨부된 일반 파일은 다운로드할 수 있다.
- 파일 탐색기에서 Altio 사이드바 입력창으로 파일을 드래그하면 해시 문자열을 입력하지 않고 첨부 블록으로 처리한다.
- Altio 사이드바에서 파일 업로드 중에도 입력창에는 텍스트를 입력할 수 있으며, 전송 버튼만 비활성화한다.
- Altio 사이드바에서 파일 업로드 중에도 추가 버튼은 활성화해 새로운 파일을 더 첨부할 수 있다.
- Altio 사이드바에서 업로드 중인 파일도 제거할 수 있도록 제거 버튼을 제공한다.
- 파일·폴더 업로드 중복 모달은 중복 판단 대상이 폴더인 경우 폴더 자체를 중복 항목으로 노출하고, 폴더 내부 개별 파일을 대신 노출하지 않는다.
- 지원하지 않는 파일 형식을 드래그 앤 드롭하면 업로드 팝오버를 열거나 업로드 목록에 추가하지 않고, 지원하지 않는 형식 안내 토스트만 노출한다.
- 파일 또는 폴더를 다른 폴더로 이동하는 것만으로는 수정일을 갱신하지 않는다. 파일 수정일은 노트와 동일하게 제목 또는 내용 변경을 기준으로 갱신한다.
- 업로드한 Markdown 파일을 열면 노트 편집 화면으로 진입한다.
- 저장 데이터가 제한에 가까워져 저장 실패가 예상되는 경우 단순 실패 토스트가 아니라 용량 또는 제한 상태를 이해할 수 있는 안내를 제공한다.

## 이유
- 파일은 노트, 내 드라이브, 공유 화면, Altio 첨부 등 여러 경로에서 다뤄지므로 다운로드와 첨부 동작 기준이 일관되어야 한다.
- 업로드 중에도 사용자가 다음 입력이나 추가 첨부를 준비할 수 있어야 하며, 실제 전송 가능 여부만 제한하면 된다.
- 파일 이동을 수정으로 처리하면 사용자가 파일 자체가 변경된 것으로 오해할 수 있다.

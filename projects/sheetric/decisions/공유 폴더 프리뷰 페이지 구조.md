# 공유 폴더 프리뷰 페이지 구조

## 상태
추가

## 날짜
2026-09-16

## 프로젝트
- Sheetric

## 결정
- 공유 폴더 프리뷰는 폴더 안내 페이지와 노트·파일 상세 페이지로 나누어 제공한다.
- 폴더 안내 페이지 상단에는 로고를 노출하되 별도 클릭 기능은 제공하지 않는다.
- 폴더 안내 페이지의 메인 영역에는 폴더명과 폴더에 포함된 노트·파일 리스트를 노출한다.
- 리스트에서 노트 또는 파일을 클릭하면 해당 항목의 상세 페이지로 이동한다.
- 노트·파일 상세 페이지 상단 왼쪽에는 폴더 안내 페이지로 돌아가는 뒤로가기 버튼을 제공한다.
- 공유 및 로그인 버튼은 기존 공개 링크 화면의 정책을 유지한다.

## 이유
- 폴더 공유 링크는 단일 노트보다 탐색 대상이 많으므로, 폴더 진입 화면과 개별 항목 상세 화면을 분리해야 한다.
- 뒤로가기 동선을 제공해야 공유 폴더 안의 여러 항목을 확인하는 흐름이 끊기지 않는다.

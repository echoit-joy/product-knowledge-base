# Altio 녹음 업로드 기능 추가

## 상태
추가

## 날짜
2026-09-21

## 프로젝트
- Sheetric

## 결정
- 노트의 `/` 블록 메뉴에서 기존 [Altio 녹음] 단일 항목을 [Altio 녹음] / [Altio 녹음 업로드] 두 항목으로 분리한다.
- [Altio 녹음 업로드]를 선택하면 노트 본문에 녹음 파일 업로드 블록이 생성되고, [파일 선택하기] 버튼 또는 블록 영역 드래그 앤 드롭으로 외부 음성 파일을 업로드할 수 있다.
- 업로드 지원 확장자는 mp3, wav, m4a로 제한한다.
- 파일 1개당 최대 업로드 용량은 500MB(최대 녹음 시간인 2시간 분량 녹음 기준 산정)로 제한한다.
- 지원하지 않는 확장자를 선택·드롭하면 업로드를 진행하지 않고 오류 토스트를 노출한다.
- 파일 용량이 제한을 초과하면 업로드를 진행하지 않고 오류 토스트를 노출한다.
- 녹음 또는 업로드 시작부터 업로드·변환 완료 또는 실패 전까지 현재 노트를 포함한 모든 노트의 [Altio 녹음], [Altio 녹음 업로드]를 모두 비활성화한다.
- [Altio 녹음]으로 시작한 녹음과 [Altio 녹음 업로드]로 시작한 파일 업로드는 이후 업로드·변환·결과 단계를 동일한 흐름과 UI로 처리한다.
- PC/Mobile 동일하게 적용한다.

## 이유
- Altio에서 직접 녹음한 파일뿐 아니라 외부에서 녹음한 음성 파일도 스크립트 변환과 요약에 활용할 수 있어야 한다.
- 두 진입 경로가 같은 처리 파이프라인을 타야 결과 UI와 재시도 로직을 하나로 유지보수할 수 있다.
- 동시에 여러 녹음·업로드가 진행되면 처리 상태를 추적하기 어려우므로, 진행 중에는 신규 진입을 막아야 한다.

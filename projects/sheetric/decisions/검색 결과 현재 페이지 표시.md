# 검색 결과 현재 페이지 표시

## 상태
수정

## 날짜
2026-06-24

## 프로젝트
- Sheetric

## 결정
- 검색 결과는 별도 페이지로 이동하지 않고 현재 페이지 안에서 표시한다.
- 검색어가 입력되고 실행되면 검색바 아래에 검색 결과 테이블을 노출한다.
- 검색 결과 화면도 기존 리스트형 화면의 테이블 구조와 동일한 기준을 따른다.

## 이유
- 검색은 현재 사용자가 보고 있는 리스트 맥락에서 이어지는 동작이다.
- 별도 페이지 이동보다 현재 페이지 내 결과 테이블 표시가 사용자의 위치 인지를 유지하기 쉽다.
- 검색바 위치와 결과 테이블을 같은 콘텐츠 영역 안에 두면 검색 흐름이 분리되지 않는다.

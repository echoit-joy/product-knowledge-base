# 삭제 예정 공유 항목 즐겨찾기·공유 아이콘 표시

## 상태
추가

## 날짜
2026-09-03

## 프로젝트
- Sheetric

## 결정
- 공유 드라이브 테이블에서 원본 소유자가 휴지통으로 이동해 삭제 예정 상태인 노트·폴더는 즐겨찾기(별) 버튼을 비활성화한다.
- 삭제 예정 상태인 노트·폴더의 제목 옆 공유 아이콘에는 작대기(사선)를 표시한다.
- 원본 소유자가 휴지통에서 항목을 복구하면 즐겨찾기 버튼과 공유 아이콘 표시를 정상 상태로 되돌린다.

## 이유
- 삭제 예정 상태의 항목은 원본이 제거될 수 있어 즐겨찾기 조작을 허용하지 않는다.
- 공유 아이콘에 작대기를 표시하면 항목을 열지 않고도 테이블에서 바로 삭제 예정 상태를 인지할 수 있다.
- [삭제 예정 공유 항목 사본 및 복구 정책](삭제%20예정%20공유%20항목%20사본%20및%20복구%20정책.md)에서 정의한 삭제 예정 상태의 테이블 UI 표현을 구체화한 결정이다.

# 공유 링크 OG 메타 노출

## 상태
추가

## 날짜
2026-06-25

## 프로젝트
- Sheetric

## 결정
- 노트 링크를 공유할 때 OG title에는 노트 제목을 사용한다.
- OG description에는 노트 본문 내용을 사용한다.
- OG 이미지는 기존 Sheetric OG 이미지를 사용한다.
- 제목은 한 줄 기준으로 노출하고 긴 제목은 말줄임 처리한다.
- 본문 설명은 두 줄 기준으로 노출하고 넘치는 내용은 말줄임 처리한다.

## 이유
- 공유 링크 미리보기에서 노트의 맥락을 바로 알 수 있어야 한다.
- 제목과 본문을 활용하면 외부 메신저나 협업 도구에서 링크 식별성이 높아진다.
- 기존 OG 이미지를 재사용하면 브랜드 일관성을 유지할 수 있다.

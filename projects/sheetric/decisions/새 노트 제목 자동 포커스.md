# 새 노트 제목 자동 포커스

## 상태
추가

## 날짜
2026-07-10

## 프로젝트
- Sheetric

## 결정
- 새 노트를 열면 제목 텍스트가 전체 선택된 상태로 자동 포커스된다.
- 사용자가 바로 입력하면 기존 제목은 새 제목으로 교체된다.
- 제목 수정 후 Enter 키를 누르면 노트 제목 변경을 저장한다.
- 제목 저장 후 노트명이 변경되었다는 토스트를 노출한다.
- Enter 입력 후 커서는 노트 본문의 첫 번째 줄로 이동한다.
- 제목 행에서 편집 시간이 표시되는 영역의 왼쪽까지 클릭 가능 범위에 포함해 제목 입력 커서를 활성화한다.

## 이유
- 새 노트 생성 직후 제목을 바로 입력할 수 있어야 작성 흐름이 끊기지 않는다.
- 제목 입력 후 본문으로 자연스럽게 이동하면 키보드 중심 작성 경험이 좋아진다.
- 제목 클릭 가능 범위를 넓히면 사용자가 정확히 텍스트 위를 클릭하지 않아도 편집을 시작할 수 있다.

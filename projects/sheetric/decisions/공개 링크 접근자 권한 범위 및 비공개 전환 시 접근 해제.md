# 공개 링크 접근자 권한 범위 및 비공개 전환 시 접근 해제

## 상태
추가

## 날짜

## 프로젝트
- Sheetric

## 결정
- 공개 링크로 공유된 노트·폴더에 접근해 공유 드라이브에 추가된 초대되지 않은 사용자는, 소유자가 해당 항목을 비공개로 전환하는 즉시 접근 권한을 잃고 공유 드라이브 목록에서도 제거된다.
- 공개 링크로 접근한 초대되지 않은 사용자는 해당 노트·폴더를 열람할 수 있지만, 다른 사용자를 초대하거나 기존 공유 사용자를 삭제하는 등 공유 대상을 관리할 수 없다.
- 이에 따라 공유 모달에서 해당 사용자에게는 사용자 초대 input과 공유 대상 목록 각 항목 우측의 더보기 버튼을 노출하지 않는다.
- 공유 모달 좌측 하단의 공개·비공개 토글은 해당 사용자에게 공개로 고정 표시하고 비활성화한다.

## 이유
- [공유 링크 별도 읽기 전용 URL](공유%20링크%20별도%20읽기%20전용%20URL.md)에서 비공개 전환 시 접근을 다시 차단하기로 했으나, [공개 링크 로그인 접근자 공유 드라이브 진입 정책](공개%20링크%20로그인%20접근자%20공유%20드라이브%20진입%20정책.md)에 따라 이미 공유 드라이브에 추가된 항목의 노출 여부는 별도로 명확히 해야 한다.
- 공개 링크로 들어온 사용자는 소유자로부터 직접 초대받은 관계가 아니므로, 공유 대상 관리 권한까지 부여하면 소유자의 공유 통제권을 벗어난다.
- 공개·비공개 토글을 비활성화해 실수로 소유자의 공개 설정을 변경하는 것을 방지한다.

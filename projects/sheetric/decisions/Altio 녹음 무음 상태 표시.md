# Altio 녹음 무음 상태 표시

## 상태
추가

## 날짜
2026-09-10

## 프로젝트
- Sheetric

## 결정
- Altio 녹음에 인식 가능한 음성이 없으면 자동으로 임의의 태그, 요약, 스크립트를 생성하지 않는다.
- 녹음 제목은 `새로운 녹음`으로 표시한다.
- 요약 탭의 태그 영역은 태그 관리 모달에 설정된 태그와 연동한다.
- 녹음 내용이 없고 설정된 태그도 없으면 태그 영역에 `아직 추가된 태그가 없습니다.`를 표시한다.
- 녹음 내용이 없으면 요약 탭에서 `한 줄 요약`과 `핵심 내용` 섹션을 노출하지 않고 `요약할 수 있는 녹음 내용이 없습니다.`를 표시한다.
- 스크립트 탭에는 `녹음된 음성이 없어 텍스트로 변환할 내용이 없습니다.`를 표시한다.

## 이유
- 실제 발화가 없는데 텍스트가 생성되면 사용자가 녹음 결과를 신뢰하기 어렵다.
- 무음 상태에서는 없는 내용을 만들어내기보다 명확한 빈 상태를 제공해야 한다.
- 태그는 녹음 내용과 별개로 사용자가 사전에 관리할 수 있으므로 기존 태그 설정과 연동한다.

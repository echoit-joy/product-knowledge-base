# 키보드 포커스 및 단축키

## 상태
수정

## 날짜
2026-07-07, 2026-08-10, 2026-08-28, 2026-08-31

## 프로젝트
- Sheetric

## 결정
- 키보드 단축키 모달의 `생성 및 실행` 탭에 아래 단축키 목록을 노출하고, 해당 키 입력 시 연결된 메뉴 또는 기능을 실행한다.
- Windows와 macOS의 단축키는 아래 기준으로 구분한다.
  - 즐겨찾기 메뉴: Windows `Alt + Shift + A` / macOS `Option + Shift + A`
  - 내 드라이브 메뉴: Windows `Alt + Shift + S` / macOS `Option + Shift + S`
  - 공유 드라이브 메뉴: Windows `Alt + Shift + D` / macOS `Option + Shift + D`
  - 워크스페이스 메뉴: Windows `Alt + Shift + F` / macOS `Option + Shift + F`
  - Altio 메뉴: Windows `Alt + Shift + Z` / macOS `Option + Shift + Z`
  - 휴지통 메뉴: Windows `Alt + Shift + X` / macOS `Option + Shift + X`
  - 새 노트: Windows `Ctrl + Shift + .` / macOS `Command + Shift + .`
  - 이전 탭: Windows `Ctrl + Shift + F` / macOS `Command + Shift + F`
  - 다음 탭: Windows `Ctrl + Shift + H` / macOS `Command + Shift + H`
  - 탭 닫기: Windows `Alt + W` / macOS `Option + W`
  - 검색: Windows `Alt + G` / macOS `Option + G`
  - Altio 사이드바: Windows `Alt + A` / macOS `Option + A`
  - 버전 저장: Windows `Alt + S` / macOS `Option + S`
  - 폴더 트리: Windows `Alt + E` / macOS `Option + E`
  - 드라이브 검색: Windows `Ctrl + Shift + E` / macOS `Command + Shift + E`
  - 단축키 표시: Windows `Ctrl + /` / macOS `Command + /`
- Altio 사이드바 단축키 입력 시 열기와 닫기를 토글한다.
- 키보드 단축키 표시 단축키 입력 시 키보드 단축키 모달의 열기와 닫기를 토글한다.
- 폴더 트리 단축키는 기존 검토안인 Shift + E 대신 Windows `Alt + E`, macOS `Option + E`를 사용한다.
- 드라이브 검색 모달 진입 시 검색 입력창에 기본 포커스를 둔다.
- 드라이브 검색 입력창에서 Tab 키를 누르면 검색 결과 리스트로 포커스를 이동한다.
- 내 드라이브에서는 Tab 키로 폴더 트리 최상단 항목에 포커스를 이동하고 이후 폴더와 노트 간 이동을 지원한다.
- 노트 화면에서는 확장 사이드바가 펼쳐져 폴더 트리가 보일 때만 폴더 트리 Tab 이동을 적용한다.
- 노트에서 사이드바 항목에 포커스가 있을 때 Esc 키를 누르면 해당 포커스를 해제하고 노트 본문 맨 아래로 포커스를 이동한다.
- 팝오버가 열린 상태에서 Esc 키를 누르면 해당 팝오버를 닫는다.
- 단축키 1~3번 항목에는 `Shift + 1/2/3` 검토안을 사용하지 않는다.

## 이유
- Shift + E는 대문자 입력과 충돌할 수 있어 사이드바 단축키로 적합하지 않다.
- 키보드만으로 검색, 탐색, 팝오버 닫기, 본문 복귀가 가능해야 접근성이 좋아진다.
- 운영체제별 단축키가 다르면 안내 문구도 실제 입력 방식과 일치해야 한다.
- `Shift + 1/2/3` 계열은 Altio 대화에서 `!`, `@`, `#` 입력과 충돌할 수 있으므로 1~3번 메뉴 단축키로 사용하지 않는다.
- 단축키의 기능 키 조합은 운영체제 간 동일하게 유지하고, Windows의 `Ctrl`·`Alt`와 macOS의 `Command`·`Option` 표기만 구분해 실제 키보드 입력과 일치시킨다.

## 결정
- Altio 사이드바는 사용자의 최신 질문과 현재 턴에 첨부된 파일·이미지를 우선 컨텍스트로 사용한다.
- 사용자가 별도 대상을 지정하지 않고 첨부 직후 요약이나 분석을 요청하면, 열려 있는 노트보다 현재 턴의 첨부파일을 우선한다.
- 사용자가 문서와 관계없는 텍스트를 직접 붙여넣고 번역이나 다듬기를 요청하면, 열려 있는 문서가 아니라 사용자가 입력한 텍스트를 대상으로 처리한다.
- 동명의 노트가 여러 개 검색되면 내부 노트 ID를 노출하지 않고 폴더 경로, 최근 수정일 등 사용자가 식별할 수 있는 정보로 구분한다.
- 노트명 검색은 공백 유무만 다른 입력도 같은 후보로 비교한다.
- 태그 목록이나 태그 기반 질문은 현재 존재하는 항목과 현재 존재하는 태그만 기준으로 답변하며, 삭제된 노트·태그는 제외한다.
- 최신 정보가 필요한 질문은 사용자가 별도 기준일을 지정하지 않는 한 질문한 시점의 최신 정보를 기준으로 답변한다.
- 현재 서비스명을 묻는 질문에는 접속 중인 서비스 맥락에 맞는 이름으로 답변한다.
- 긴 문서 번역이나 요약은 중간에 끊기지 않도록 전체 대상 범위를 유지해 처리한다.
- Markdown 문서를 읽을 때는 굵게, 취소선, 제목, 목록 등 서식이 문서 의미를 구성하는 경우 해당 구조를 반영해 이해한다.
- 응답 생성 중에는 기술 내부 용어를 사용자에게 노출하지 않고 일반 사용자가 이해할 수 있는 표현으로 안내한다.

## 이유
- Altio는 열려 있는 문서, 현재 입력, 첨부파일, 이전 대화가 함께 존재하는 화면에서 동작하므로 우선순위가 명확해야 한다.
- 내부 ID나 구현 용어를 노출하면 사용자가 답변을 이해하거나 대상을 식별하기 어렵다.
- 삭제된 항목과 과거 첨부파일이 현재 질문에 섞이면 실제 작업 맥락과 다른 답변이 생성될 수 있다.

# 테이블 행 선택 동작

## 상태
추가

## 날짜
2026-06-17

## 프로젝트
- Sheetric

## 결정
- 테이블 행을 우클릭하면 해당 행의 체크박스를 활성화하고 선택 배경을 적용한다.
- 단일 행 우클릭 시 기존에 선택된 다른 행은 선택 해제한다.
- 2개 이상의 행이 선택된 상태에서 선택 영역을 우클릭하면 기존 선택을 유지한 채 컨텍스트 메뉴를 연다.
- Shift + 클릭 시 마지막으로 선택한 행을 기준으로 구간 내 모든 항목을 일괄 선택한다.
- 테이블 행을 드래그할 때 해당 행의 체크박스는 자동 선택된다.

## 이유
- 우클릭 메뉴는 현재 작업 대상과 선택 상태가 일치해야 한다.
- 다중 선택 상태에서 우클릭할 때 선택이 해제되면 일괄 작업 흐름이 끊긴다.
- Windows 탐색기와 Google Drive에 가까운 선택 동작을 제공하면 사용자가 예측하기 쉽다.

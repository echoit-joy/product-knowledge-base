# 검색바 리스트 상단 이동

## 상태
수정

## 날짜
2026-07-13

## 프로젝트
- Sheetric

## 결정
- Sheetric의 리스트형 화면(즐겨찾기, 내드라이브, 휴지통)에서 검색바는 좌측 사이드바/태그 필터 영역이 아니라 콘텐츠 리스트 상단 헤더 영역에 배치한다.
- 검색바는 화면 제목과 항목 수 표시 오른쪽, 다운로드/삭제 등 선택 항목 액션 버튼 왼쪽에 둔다.
- 좌측 영역은 태그 필터와 폴더 트리에 집중한다.
- 적용 기준 화면 예시는 즐겨찾기 리스트 화면이다.

## 이유
- 검색은 현재 리스트 콘텐츠를 대상으로 하는 동작이므로 필터 사이드바보다 리스트 헤더에 두는 편이 화면 맥락과 맞다.
- 드라이브 구조에서 좌측은 폴더 트리가 있어야 조작이 편리하다.
- 리스트 선택 액션 버튼과 같은 상단 조작 영역에 배치하면 검색, 선택, 다운로드, 삭제 흐름을 한 곳에서 처리할 수 있다.

# 검색바 리스트 상단 이동

## 상태
수정

## 날짜
2026-07-13

## 프로젝트
- Sheetric

## 결정
- Sheetric의 리스트형 화면에서 검색바는 좌측 사이드바/태그 필터 영역이 아니라 콘텐츠 리스트 상단 헤더 영역에 배치한다.
- 검색바는 화면 제목과 항목 수 표시 오른쪽, 다운로드/삭제 등 선택 항목 액션 버튼 왼쪽에 둔다.
- 좌측 영역은 태그 필터와 필터 적용/초기화 동작에 집중한다.
- 적용 기준 화면 예시는 즐겨찾기 리스트 화면이다.

## 이유
- 검색은 현재 리스트 콘텐츠를 대상으로 하는 동작이므로 필터 사이드바보다 리스트 헤더에 두는 편이 화면 맥락과 맞다.
- 태그 필터와 텍스트 검색의 역할을 분리해 사용자가 현재 적용 중인 조작 영역을 더 쉽게 구분할 수 있다.
- 리스트 선택 액션 버튼과 같은 상단 조작 영역에 배치하면 검색, 선택, 다운로드, 삭제 흐름을 한 곳에서 처리할 수 있다.

## 참고
- 2026-07-13 사용자 제공 화면 기준: 즐겨찾기 화면에서 검색바가 콘텐츠 상단 헤더 오른쪽에 위치함.

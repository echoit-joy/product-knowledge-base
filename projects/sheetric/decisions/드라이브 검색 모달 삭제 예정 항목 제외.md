# 드라이브 검색 모달 삭제 예정 항목 제외

## 상태
추가

## 날짜
2026-09-03

## 프로젝트
- Sheetric

## 결정
- 드라이브 검색 모달의 검색 결과에서 원본 소유자가 휴지통으로 이동해 삭제 예정 상태인 노트·폴더는 노출하지 않는다.
- 원본 소유자가 휴지통에서 해당 항목을 복구하면 검색 결과에도 다시 노출한다.

## 이유
- 드라이브 검색 모달에는 공유 상태를 구분하는 공유 아이콘이 없어, 검색 결과만으로는 삭제 예정 상태인지 확인하기 어렵다.
- 삭제 예정 항목을 결과에서 제외하면 별도 표시 없이도 혼동을 방지할 수 있다.
- [삭제 예정 공유 항목 사본 및 복구 정책](삭제%20예정%20공유%20항목%20사본%20및%20복구%20정책.md)에서 정의한 삭제 예정 상태의 노출 규칙을 드라이브 검색 모달에도 동일하게 적용한 결정이다.

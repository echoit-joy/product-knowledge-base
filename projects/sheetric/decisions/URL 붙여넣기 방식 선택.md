# URL 붙여넣기 방식 선택

## 상태
추가

## 날짜
2026-07-23

## 프로젝트
- Sheetric

## 결정
- 노트 본문에 URL을 붙여넣으면 붙여넣기 방식을 선택하는 팝오버를 노출한다.
- 팝오버에는 `URL로 붙여넣기`와 `임베드로 붙여넣기`를 제공한다.
- `URL로 붙여넣기`를 선택하면 붙여넣은 주소를 URL 링크 형태로 본문에 삽입한다.
- `임베드로 붙여넣기`를 선택하면 해당 URL을 임베드/미리보기 형태의 블록으로 삽입한다.
- 사용자가 선택하기 전에는 임의로 URL 또는 임베드 중 하나로 자동 확정하지 않는다.

## 이유
- 같은 URL이라도 사용자는 문맥에 따라 단순 링크로 남기고 싶을 수도 있고, 임베드 형태로 보여주고 싶을 수도 있다.
- 붙여넣기 직후 선택지를 제공하면 별도 메뉴를 찾지 않아도 원하는 형태로 바로 삽입할 수 있다.
- 자동 변환을 강제하지 않으면 사용자가 작성 중인 문서의 밀도와 표현 방식을 직접 조절할 수 있다.

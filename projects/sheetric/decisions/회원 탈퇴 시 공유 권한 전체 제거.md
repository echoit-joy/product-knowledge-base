# 회원 탈퇴 시 공유 권한 전체 제거

## 상태
추가

## 날짜
2026-09-04

## 프로젝트
- Sheetric

## 결정
- 사용자가 회원 탈퇴하면 해당 사용자가 공유받고 있던 모든 노트·폴더에서 공유 권한을 제거한다.
- 상위 폴더 공유를 통해 부여된 권한과 개별 항목에 직접 부여된 권한을 구분하지 않고 모두 제거한다.
- 권한 제거 후 해당 항목에 남은 공유 사용자가 없으면 공유 아이콘을 노출하지 않는다.
- 권한 제거 후에도 다른 공유 사용자가 남아 있으면 공유 아이콘은 계속 노출한다.

## 이유
- 탈퇴한 사용자는 계정 자체가 사라지므로 공유 경로(개별·폴더)를 구분해서 유지할 실익이 없다.
- 공유 아이콘은 실제로 공유 중인 사용자가 남아 있는지를 나타내야 하므로, 잔여 공유자 유무에 따라 노출 여부를 결정한다.
- [폴더 공유 권한 전파](폴더%20공유%20권한%20전파.md)에서 정의한 "소유자의 공유 대상 삭제"는 해당 공유 경로로 부여된 권한만 제거하지만, 회원 탈퇴는 공유 경로 구분 없이 전체 권한을 제거하는 별도 케이스로 관리한다.

# 업로드 파일 중복 모달 단일 항목 버튼명 변경

## 상태
수정

## 날짜
2026-09-08

## 프로젝트
- Sheetric

## 결정
- 업로드하는 파일 1개가 기존 파일과 이름이 중복될 때 노출되는 모달의 하단 버튼명을 변경한다.
  - as-is: 모두 취소 / 모두 덮어쓰기
  - to-be: 취소 / 덮어쓰기
- 복수 항목이 중복되는 경우의 버튼명(모두 취소 / 모두 덮어쓰기)은 변경하지 않고 그대로 유지한다.
- 관련 기능: 기능정의_2-2차 main_01_66(업로드 모달 > 파일 중복 확인 모달, 신규 추가)

## 이유
- 단일 항목만 처리하는 상황에서 "모두"라는 표현이 사용자에게 혼동을 준다는 개발/수정 요청에 따름.

# Altio 녹음 종료 및 표시 기준

## 상태
수정

## 날짜
2026-09-11, 2026-09-16, 2026-09-21, 2026-09-22

## 프로젝트
- Sheetric

## 결정
- Altio 녹음 중에는 녹음 타이머가 중간에 초기화되지 않고 실제 녹음 진행 시간을 유지한다.
- 녹음을 시작한 뒤 다른 노트로 이동하더라도 녹음 결과는 녹음을 시작한 원래 노트에 저장한다.
- 녹음이 진행 중인 대상 노트가 삭제되면 진행 중인 녹음을 종료하고 녹음 UI도 함께 닫는다.
- 모바일에서 키보드가 열리면 녹음 UI는 키보드에 가려지지 않도록 키보드 상단으로 이동하고, 키보드를 닫으면 기존 하단 위치로 돌아간다.
- 녹음 중 다른 노트나 화면으로 이동할 수 있으므로, 녹음 바에는 녹음을 시작한 노트의 이름을 함께 표시한다.
- 녹음 블록의 메모 탭은 현재 범위에서 노출하지 않는다.
- 짧은 녹음이나 음성 인식 결과가 불명확한 경우에도 기본 안내 텍스트와 언어는 한국어 기준으로 제공한다.
- Altio 녹음으로 생성된 블록을 클릭했을 때 일반 텍스트 드래그 팝오버를 노출하지 않는다.
- 녹음 블록의 개별 기록에는 더보기 버튼을 제공하고, 기록 영역을 우클릭해도 동일한 팝오버를 노출한다.
- Altio 녹음이 진행 중인 블록에서 6dot 팝오버의 `삭제`를 클릭하면 기존 `녹음 종료` 모달을 노출한다.
  - 모달에서 취소하면 모달을 닫고 진행 중인 녹음을 유지한다.
  - 모달에서 확인하면 기존 녹음 종료 후 처리 흐름을 따른다.
- (2026-09-21) 노트에 머무는 동안에는 녹음을 노트 본문 내 녹음 블록 UI로 노출하고, 기존 화면 중앙 하단 플로팅 녹음 UI는 다른 노트·탭·화면으로 이동했을 때만 노출한다. 원래 노트로 복귀하면 다시 블록 UI로 전환한다.
- (2026-09-21) 녹음 진행 중에는 타이머 좌측에 빨간 점(●) 인디케이터를 깜빡임(blink) 애니메이션으로 노출한다. [일시정지] 상태에서는 깜빡임을 멈추고 고정 표시로 전환하며, 재개 시 다시 깜빡인다.
- (2026-09-21) 녹음 파일 업로드 중·스크립트 변환 및 요약 생성 중에 다른 노트·탭·화면으로 이동해도 처리는 계속 유지된다.
- (2026-09-21) 녹음 파일 업로드 중 브라우저 탭 닫기·새로고침·브라우저 종료가 확정되면 업로드가 중단되며, 재접속 시 녹음 파일 업로드 실패 상태로 노출한다.
- (2026-09-21) 스크립트 변환 및 요약 생성 중에는 브라우저 이탈 여부와 무관하게 서버 처리가 계속되며, 재접속 시 진행 중이면 생성 중 상태를, 완료됐으면 결과를 그대로 반영한다.
- (2026-09-22) Altio 녹음 또는 Altio 녹음 업로드를 통해 생성 완료된 녹음 결과 블록의 제목 왼쪽에 접기·펼치기 아이콘을 노출한다.
- (2026-09-22) 접기·펼치기 아이콘 클릭 시 블록 내용을 접거나 펼치며, 아이콘 방향은 현재 상태에 맞게 전환한다.
  - 펼친 상태: 제목, `새 노트로 추출`, 탭 및 선택된 탭의 내용 노출
  - 접힌 상태: 제목과 `새 노트로 추출`만 노출하고, 탭 및 탭 내용은 미노출

## 이유
- 녹음 결과의 저장 위치와 종료 조건이 불명확하면 사용자가 어느 노트에 기록이 남는지 예측하기 어렵다.
- 녹음 중 노트 이동, 노트 삭제, 모바일 키보드 노출은 녹음 기능에서 자주 발생할 수 있는 상태 변화이므로 동작 기준을 명확히 해야 한다.
- 현재 열린 노트와 녹음 대상 노트가 달라질 수 있으므로, 녹음 바에서 대상 노트를 확인할 수 있어야 한다.
- 제공하지 않는 탭이나 일반 텍스트 편집 팝오버가 노출되면 녹음 블록 전용 동작과 충돌한다.
- 녹음 진행 중 블록 삭제가 즉시 실행되면 진행 중인 녹음이 예고 없이 유실될 수 있으므로 종료 여부를 먼저 확인해야 한다.
- (2026-09-21) 노트 안에서는 블록으로, 노트를 벗어나면 기존 방식으로 노출해야 두 UI가 충돌하지 않고 어느 화면에서도 진행 상태를 계속 인지할 수 있다.
- (2026-09-21) 녹음 중임을 시각적으로 명확히 구분해야 하며, 일시정지 상태에서도 계속 깜빡이면 실제 녹음 여부를 오인할 수 있다.
- (2026-09-21) 업로드는 클라이언트가 파일을 전송하는 구간이라 탭 종료 시 전송이 끊기지만, 생성은 서버 비동기 작업이라 탭 종료와 무관하게 계속 진행될 수 있다.
- (2026-09-22) 긴 요약이나 스크립트가 포함된 녹음 결과 블록을 접을 수 있어야 노트 내 다른 내용을 빠르게 탐색할 수 있다.

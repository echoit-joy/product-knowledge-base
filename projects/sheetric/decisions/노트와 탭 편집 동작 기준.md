# 노트와 탭 편집 동작 기준

## 상태
수정

## 날짜
2026-09-11

## 프로젝트
- Sheetric

## 결정
- 열린 노트가 삭제되면 해당 노트 탭도 함께 닫는다.
- 삭제된 노트 탭이 남아 사용자가 다시 클릭한 경우에는 탭을 제거하고 삭제되었거나 존재하지 않는 링크 안내를 한 번만 노출한다.
- 노트 화면에서 현재 노트를 삭제하면 다른 노트가 잠깐 노출되지 않고 이전 목록 또는 사용자가 진입했던 화면으로 이동한다.
- Altio 패널과 버전 기록 패널은 서로 배타적으로 동작하며, 하나를 열면 다른 하나는 닫는다.
- 삭제, 이동, 복원, 영구 삭제, 새 폴더, 이름 변경, 사용자 이름 변경 등 확인 동작이 있는 모달에서는 Enter 입력으로 주요 액션을 실행하고 모달을 닫는다.
- 노트 제목 입력 후 Enter를 누르면 제목 저장 동작은 유지하고 포커스는 본문으로 이동한다.
- 링크를 삽입하면 링크 텍스트임을 알 수 있도록 밑줄을 적용한다.
- 링크를 제거할 때는 링크 속성만 제거하고, 굵게·기울임·취소선·밑줄 등 기존 텍스트 서식은 유지한다.
- 여러 행의 정렬을 한 번에 변경한 뒤 되돌리기를 실행하면 변경된 행들을 한 번에 이전 상태로 복원한다.
- 표 안에서 텍스트를 삭제한 뒤 다시 입력해도 입력 순서가 바뀌지 않아야 한다.

## 이유
- 삭제된 노트 탭이나 패널 상태가 남아 있으면 사용자가 현재 작업 대상을 오해할 수 있다.
- Enter, 제목 저장, 링크 서식, 되돌리기 같은 편집 동작은 반복 사용성이 높아 일관된 기준이 필요하다.
- 링크 제거는 링크 상태만 변경하는 작업이며, 사용자가 의도한 다른 텍스트 서식을 함께 없애면 안 된다.

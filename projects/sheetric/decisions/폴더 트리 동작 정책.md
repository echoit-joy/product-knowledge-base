# 폴더 트리 동작 정책

## 상태
수정

## 날짜
2026-07-03

## 프로젝트
- Sheetric

## 결정
- 내 드라이브 폴더 트리의 정렬 기준은 이름순으로 고정한다.
- 로그아웃 이후에도 사이드바 내 폴더 열기와 닫기 상태를 저장한다.
- 하위 노트나 폴더가 없는 폴더는 클릭해도 열린 아이콘으로 변경하지 않고 닫힌 폴더 아이콘을 유지한다.
- 폴더 트리의 폴더를 우클릭하면 새 노트와 새 폴더를 추가할 수 있는 팝오버를 노출한다.
- 폴더 트리의 빈 공간을 우클릭하면 새 노트와 새 폴더로 구성된 팝오버를 노출한다.

## 이유
- 폴더 트리는 사용자가 반복적으로 탐색하는 구조이므로 정렬과 열림 상태가 안정적으로 유지되어야 한다.
- 빈 폴더를 열린 상태로 표시하면 하위 항목이 있는 것처럼 오해할 수 있다.
- 폴더 트리와 빈 공간의 우클릭 생성 동작은 Windows 탐색기와 유사한 사용 경험을 제공한다.

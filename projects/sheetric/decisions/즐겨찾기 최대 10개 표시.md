# 즐겨찾기 최대 10개 표시

## 상태
수정

## 날짜
2026-06-15

## 프로젝트
- Sheetric

## 결정
- 메인 페이지의 즐겨찾기 섹션에는 최대 10개 항목만 노출한다.
- 즐겨찾기 항목은 최신 수정일 기준으로 정렬한다.
- 즐겨찾기 항목이 10개를 초과해도 메인 페이지에는 상위 10개만 표시한다.

## 이유
- 메인 페이지는 빠른 접근을 위한 요약 영역이므로 무제한 노출에 적합하지 않다.
- 최신 수정일 기준 정렬은 최근 작업 맥락과 맞다.
- 노출 수를 제한하면 메인 페이지의 정보 밀도를 안정적으로 유지할 수 있다.

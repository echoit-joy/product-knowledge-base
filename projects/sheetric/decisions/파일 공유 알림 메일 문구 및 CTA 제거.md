# 파일 공유 알림 메일 문구 및 CTA 제거

## 상태
추가

## 날짜
2026-09-09

## 프로젝트
- Sheetric

## 결정
- 파일 공유 시 발송되는 공유 알림 메일의 문구를 다음과 같이 확정한다.
  - 메일 제목: `'{file_title}' 파일 공유 알림`
  - Description: `{inviter_name}({inviter_email})님이 '{file_title}' 파일을 공유했습니다.`
- 해당 메일에는 CTA 버튼을 노출하지 않는다 (기존 노트·폴더 공유 알림 메일에 있던 CTA 버튼을 파일 공유 알림 메일에서는 삭제).

## 이유
- 파일은 별도 편집 화면이 없어(미리보기·다운로드 위주) CTA로 안내할 목적지가 노트·폴더와 다르므로, 파일 공유 알림 메일에서는 CTA 버튼을 제외하기로 확정.

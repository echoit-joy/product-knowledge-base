# 노트 다운로드 Markdown 정책

## 상태
수정

## 날짜
2026-06-18

## 프로젝트
- Sheetric

## 결정
- 노트를 개별 다운로드할 때 파일 형식은 Markdown(.md)으로 저장한다.
- 여러 노트를 ZIP으로 다운로드할 때도 각 노트 파일 형식은 Markdown(.md)으로 유지한다.
- ZIP 파일명은 다운로드 대상이 포함된 폴더명을 기준으로 정한다.
- 내 드라이브 최상단에 있는 항목을 ZIP으로 다운로드할 경우 ZIP 파일명은 내 드라이브로 정한다.

## 이유
- 개별 다운로드와 다중 다운로드의 파일 형식이 다르면 사용자가 결과물을 예측하기 어렵다.
- 노트는 Markdown 기반 콘텐츠로 관리되므로 .txt보다 .md가 적합하다.
- ZIP 파일명을 포함 폴더 기준으로 정하면 다운로드 파일을 구분하기 쉽다.

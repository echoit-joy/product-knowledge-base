# 추가 팝오버 미제공 메뉴 제거

## 상태
대체됨

## 날짜
2026-06-16

## 프로젝트
- Sheetric

## 대체 결정
- [파일 업로드 및 미리보기 제공](파일%20업로드%20및%20미리보기%20제공.md)

## 결정
- 현재 개발 범위에서 제공하지 않는 메뉴는 비활성화 상태로 노출하지 않고 제거한다.
- 추가 팝오버에서 새 시트 메뉴는 제거한다.
- 추가 팝오버에서 파일 업로드와 폴더 업로드 메뉴는 제거한다.
- 제공하지 않는 기능을 신규 spec 또는 QA에 비활성 메뉴로 포함하지 않는다.

## 이유
- 제공하지 않는 기능을 비활성 상태로 노출하면 사용자가 곧 사용할 수 있는 기능으로 오해할 수 있다.
- 현재 개발 범위에 없는 기능은 화면에서 제거하는 편이 명확하다.
- spec 작성 시 미제공 메뉴가 남아 있으면 구현 범위가 불필요하게 커진다.
- 2차 기능정의서에서 파일·폴더 업로드가 현재 제공 범위로 확정되어 업로드 메뉴 제거 정책은 현재 기준으로 사용하지 않는다.

# 태그 필터 노출 및 정렬

## 상태
수정

## 날짜
2026-06-09, 2026-09-14

## 프로젝트
- Sheetric

## 결정
- 즐겨찾기 화면의 태그 필터에는 즐겨찾기 설정된 노트에 적용된 태그만 노출한다.
- 태그가 없을 때는 기존 태그 영역 레이아웃을 유지하고 status.tag.desc 안내 문구를 노출한다.
- 태그 정렬 1순위는 태그된 항목 수 내림차순이다.
- 태그 정렬 2순위는 최신 생성 태그 우선이다.
- 검색어를 입력했다가 지워도 태그 필터의 정렬 순서는 임의로 바뀌지 않는다.
- 삭제된 노트나 현재 화면 범위 밖 항목에만 남아 있는 태그는 해당 화면의 태그 필터와 검색 팝오버에 노출하지 않는다.
- 삭제했던 노트를 복원하면 해당 노트의 태그도 현재 화면의 태그 필터와 검색 대상에 다시 반영한다.

## 이유
- 즐겨찾기 화면의 태그 필터는 해당 화면에서 필터링 가능한 항목만 보여야 한다.
- 태그가 없는 상태에서도 영역이 사라지면 레이아웃이 흔들리고 사용자가 기능 위치를 잃을 수 있다.
- 많이 사용된 태그와 최근 생성 태그를 우선하면 탐색 효율이 높아진다.

# 지원하지 않는 파일 드래그앤드롭 처리

## 상태
추가

## 날짜
2026-09-10

## 프로젝트
- Sheetric

## 결정
- 사용자가 지원하지 않는 파일 형식을 드래그 앤 드롭으로 첨부하면 업로드 팝오버를 노출하지 않는다.
- 이 경우 지원하지 않는 파일 형식임을 안내하는 토스트만 노출한다.
- 지원하지 않는 파일은 업로드 대기 목록이나 업로드 진행 목록에 추가하지 않는다.

## 이유
- 업로드할 수 없는 파일에 업로드 팝오버가 열리면 사용자가 업로드가 가능한 상태로 오해할 수 있다.
- 실패가 확정된 항목은 진행 UI에 넣지 않고 즉시 안내하는 편이 명확하다.
- 파일 업로드 흐름에서 지원 가능 여부를 초기에 차단해야 불필요한 후속 오류를 줄일 수 있다.

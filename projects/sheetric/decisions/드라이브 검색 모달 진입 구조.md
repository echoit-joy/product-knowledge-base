# 드라이브 검색 모달 진입 구조

## 상태
수정

## 날짜
2026-08-31

## 프로젝트
- Sheetric

## 결정
- 드라이브 검색 모달의 최초 화면은 특정 드라이브의 폴더 목록이 아닌 드라이브 유형 선택 화면으로 제공한다.
- 최초 화면에 `내 드라이브`와 `공유 드라이브` 항목을 함께 노출한다.
- 사용자가 드라이브를 선택한 이후 해당 드라이브의 1depth 폴더 목록으로 진입한다.
- 기존처럼 `내 드라이브`를 기본값으로 적용하여 1depth 폴더 목록을 바로 노출하지 않는다.
- Windows에서 `Ctrl + Shift + E`, macOS에서 `Command + Shift + E` 입력 시 드라이브 검색 모달을 오픈한다.

## 이유
- 2차 개발에서 공유 드라이브가 추가되어 검색 대상을 먼저 구분해야 한다.
- 특정 드라이브를 기본값으로 두면 다른 드라이브의 항목을 찾을 수 있다는 점을 인지하기 어렵다.
- 최초 단계에서 검색 범위를 명시적으로 선택하도록 하여 내 드라이브와 공유 드라이브를 동일한 진입 구조로 제공한다.

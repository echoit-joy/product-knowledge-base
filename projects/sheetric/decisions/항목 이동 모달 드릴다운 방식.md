# 항목 이동 모달 드릴다운 방식

## 상태
수정

## 날짜
2026-06-10

## 프로젝트
- Sheetric

## 결정
- 항목 이동 모달은 깊은 폴더 트리를 그대로 펼치는 방식 대신 드릴다운 방식을 사용한다.
- 사용자는 현재 단계의 폴더 목록을 보고 하위 폴더로 진입하며 목적 위치를 선택한다.
- 항목 이동 모달의 리스트 영역은 한 번에 최대 8개 항목을 노출한다.
- 8개를 초과하는 경우 리스트 영역에 스크롤을 표시한다.

## 이유
- 트리 구조를 모달 안에 그대로 펼치면 depth가 깊어질수록 폴더명이 잘리고 선택이 어려워진다.
- Google Drive와 유사한 드릴다운 방식은 좁은 모달 안에서도 위치 선택을 명확하게 만든다.
- 최대 노출 개수와 스크롤 기준을 정하면 모달 높이가 불필요하게 흔들리지 않는다.

# 업로드 파일 공유 기능 추가

## 상태
수정

## 날짜
2026-09-08

## 프로젝트
- Sheetric

## 결정
- 업로드된 파일(노트·폴더 외 첨부/업로드 파일)도 공유할 수 있도록 공유 기능을 추가한다.
- 테이블에서 파일을 우클릭하거나 더보기 버튼을 클릭했을 때 노출되는 컨텍스트 메뉴의 최상단에 [공유] 메뉴를 노출한다.
- as-is: [공유] 메뉴는 노트·폴더에만 노출되고 파일에는 미노출.
- 적용 범위(all): MainPage·내 드라이브·즐겨찾기·노트(폴더트리)·공유 드라이브
- 관련 기능: 기능정의_2-2차 common_01_01(컨텍스트 메뉴 팝오버 — MainPage·내드라이브·즐겨찾기·노트), common_01_02(컨텍스트 메뉴 팝오버 — 공유드라이브)

## 이유
- 업로드 파일도 노트·폴더와 동일하게 공유 가능해야 한다는 개발 요청에 따름.

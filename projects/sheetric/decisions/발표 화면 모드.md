# 발표 화면 모드

## 상태
추가

## 날짜
2026-06-26

## 프로젝트
- Sheetric

## 결정
- 노트 더보기 팝오버에 발표 화면 모드를 제공한다.
- 발표 화면 모드 진입 시 Navbar, Tab Bar, Sidebar를 모두 숨긴다.
- 숨겨진 영역만큼 노트 제목과 본문 영역을 확장한다.
- Esc 키를 누르면 발표 화면 모드를 종료하고 기존 화면 상태로 복귀한다.

## 이유
- 발표나 공유 상황에서는 편집 외곽 UI보다 노트 내용 자체가 우선이다.
- 화면 주변 UI를 숨기면 노트 콘텐츠를 더 넓게 보여줄 수 있다.
- Esc 종료는 전체화면 계열 인터랙션에서 사용자가 기대하는 기본 동작이다.

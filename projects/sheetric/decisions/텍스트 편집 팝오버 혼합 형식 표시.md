# 텍스트 편집 팝오버 혼합 형식 표시

## 상태
추가

## 날짜
2026-07-10

## 프로젝트
- Sheetric

## 결정
- 노트에서 여러 종류의 텍스트 형식이 적용된 내용을 한 번에 선택하면 텍스트 편집 팝오버의 텍스트 형식 이름을 `혼합`으로 표시한다.
- 텍스트 형식 상세 팝오버는 이번 결정 범위에서 추가 수정하지 않는다.

## 이유
- 선택 영역 안에 서로 다른 텍스트 형식이 섞여 있을 때 단일 형식처럼 보이면 사용자가 현재 상태를 오해할 수 있다.
- 혼합 상태를 명시하면 편집 전 현재 선택 영역의 서식 상태를 더 정확히 이해할 수 있다.

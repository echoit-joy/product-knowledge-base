# 휴지통 폴더 복원 중복 처리

## 상태
추가

## 날짜
2026-09-23

## 프로젝트
- Sheetric

## 결정
- 휴지통에서 복원하는 폴더와 내 드라이브의 복원 위치에 있는 폴더명이 중복되면 `항목 중복` 모달을 노출한다.
- 모달 문구는 다음과 같이 제공한다.
  - `이동하려는 위치에 동일한 폴더가 있습니다.`
  - `폴더를 병합하고, 중복된 파일은 복원하는 파일로 덮어쓰시겠습니까?`
- 중복 항목 리스트에는 폴더 내부의 개별 파일이 아니라 중복된 폴더명을 표시한다.
- 모달 하단에는 `취소`, `덮어쓰기` 버튼을 제공한다.
- `덮어쓰기`를 선택하면 기존 로직과 동일하게 폴더를 병합하고, 이름이 중복된 파일은 복원하는 파일로 덮어쓴다.

## 이유
- 폴더 복원 시 충돌 단위가 폴더인 경우 내부 파일 전체가 아니라 병합 대상 폴더를 먼저 확인할 수 있어야 한다.
- 기존 폴더 병합과 중복 파일 덮어쓰기 동작은 유지하면서 모달의 표시 대상과 설명을 실제 처리 단위에 맞춘다.

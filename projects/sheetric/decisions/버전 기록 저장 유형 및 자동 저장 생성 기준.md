# 버전 기록 저장 유형 및 자동 저장 생성 기준

## 상태
추가

## 날짜
2026-09-22

## 프로젝트
- Sheetric

## 결정
- 신규로 생성되는 버전 기록의 저장 유형은 `자동 저장`과 `사용자 저장` 두 가지로 구분한다.
- `Altio 저장` 유형은 제거하며, Altio 기능 사용을 별도의 버전 유형이나 독립적인 버전 생성 사유로 처리하지 않는다.
- 사용자가 버전 저장 기능을 직접 실행한 기록은 `사용자 저장`으로 생성한다.
- 노트 본문의 실제 자동 저장 동작과 기존 저장 트리거는 변경하지 않고 유지한다. 현재 기준 Save는 7초 주기 및 blur·unmount·beforeunload 시 수행한다.
- 자동 저장 버전 기록은 노트 내용이 변경된 경우에만 생성하며, 노트별 자동 저장 버전의 생성 간격은 최소 1분으로 제한한다.
- 직전 자동 저장 버전 생성 이후 내용이 변경되지 않은 경우에는 1분이 지나도 새 기록을 생성하지 않는다.
- 한번 생성된 자동 저장 버전 기록은 이후 1분 이내에 노트 내용이 다시 변경되더라도 최신 내용으로 갱신하거나 덮어쓰지 않는다.
- 1분 제한 구간에 추가 변경이 발생한 경우 새 자동 저장 버전을 생성하지 않으며, 다음 생성 가능 시점 이후에도 변경 내용이 있는 경우 새 버전으로 생성한다.
- 자동 저장 버전 생성 주기와 생성된 버전 불변 규칙은 정책 적용 이후 신규로 생성되는 버전부터 적용한다.

## 이유
- Altio 사용 여부와 관계없이 버전 기록의 저장 유형을 사용자의 직접 저장과 시스템 자동 저장으로 단순화할 필요가 있다.
- 실제 자동 저장은 유지하면서 버전 기록만 일정 간격으로 남겨야 편집 내용 보호와 기록 과다 생성을 함께 방지할 수 있다.
- 변경이 없는 상태의 중복 버전을 생성하지 않고 자동 저장 버전의 생성 간격을 최소 1분으로 제한해야 버전 기록이 과도하게 쌓이지 않는다.
- 생성된 버전을 갱신하지 않아야 다른 탭에서 과거 버전을 열람하는 중에도 해당 기록의 내용이 변경되지 않는다.

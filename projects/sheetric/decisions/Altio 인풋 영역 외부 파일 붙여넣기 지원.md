# Altio 인풋 영역 외부 파일 붙여넣기 지원

## 상태
추가

## 날짜
2026-09-08

## 프로젝트
- Sheetric

## 결정
- 사용자가 외부(OS 파일 탐색기, 다른 앱 등)에서 파일이나 사진을 복사한 뒤 Altio 채팅 입력 영역에 붙여넣기(Ctrl+V) 하면, 해당 항목이 첨부파일로 붙여넣기(첨부) 처리된다.
- 기존에는 OS 파일 드래그 앤 드롭 첨부만 지원했으며, 클립보드 붙여넣기 방식의 첨부는 지원하지 않았다.
- 관련 기능: features/feature-index.md `altio-attachment-lifecycle`

## 이유
- 드래그 앤 드롭 외에 복사-붙여넣기로도 파일/사진을 빠르게 첨부할 수 있어야 한다는 개발 요청에 따름.

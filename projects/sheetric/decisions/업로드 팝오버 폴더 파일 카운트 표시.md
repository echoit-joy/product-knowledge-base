# 업로드 팝오버 폴더 파일 카운트 표시

## 상태
수정

## 날짜
2026-09-08, 2026-09-23

## 프로젝트
- Sheetric

## 결정
- 업로드 팝오버(모달)에서 폴더 업로드 시, 폴더명 우측에 "완료 파일 수/전체 파일 수" 형식으로 카운트를 표시한다. (예: 4/5개)
- 완료 파일 수에는 업로드에 성공한 파일만 포함하고, 업로드에 실패한 파일은 포함하지 않는다.
- 전체 파일 수에는 업로드를 시도한 성공·실패 파일을 모두 포함한다.
- 폴더 내 파일이 1개씩 업로드에 성공할 때마다 완료 파일 수를 실시간으로 증가시킨다.
- 모든 파일의 업로드 시도가 종료된 후에도 카운트 표시는 계속 유지한다.
- 폴더 내 파일이 하나 이상 업로드에 실패하면 `완료 파일 수/전체 파일 수` 영역에 언더라인을 표시한다.
- 언더라인이 표시된 카운트 영역을 클릭하면 `업로드 실패` 모달을 노출한다.
- `업로드 실패` 모달은 다음과 같이 구성한다.
  - 안내 문구: `파일 업로드 중 문제가 발생했습니다.`
  - 목록: 해당 폴더에서 업로드에 실패한 파일명
  - 하단 버튼: `확인`
- 관련 기능: 기능정의_2-2차 main_01_67(업로드 모달 > 폴더 파일 카운트 표시, 신규 추가)

## 이유
- 폴더 단위 업로드 진행 상황을 사용자가 실시간으로 확인할 수 있어야 한다는 개발 요청에 따름.
- 실패한 파일을 완료 건수에 포함하면 실제 업로드 성공 결과를 확인할 수 없으므로 성공한 파일만 완료 건수로 집계해야 한다.
- 일부 파일만 실패한 폴더에서도 실패 파일을 바로 확인할 수 있어야 재업로드 대상을 판단할 수 있다.

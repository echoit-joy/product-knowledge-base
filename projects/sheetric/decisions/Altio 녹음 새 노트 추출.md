# Altio 녹음 새 노트 추출

## 상태
추가

## 날짜
2026-09-16

## 프로젝트
- Sheetric

## 결정
- Altio 녹음 블록의 요약 탭 우측 상단에 `새 노트로 추출` 버튼을 제공한다.
- `새 노트로 추출` 버튼을 클릭하면 `회의록`, `후속 업무 체크리스트` 옵션을 가진 드롭다운 팝오버를 노출한다.
- 옵션을 선택하면 녹음 제목을 기준으로 새 노트를 생성한다.
  - 회의록 선택 시 제목은 `녹음 제목_회의록` 형식을 사용한다.
  - 후속 업무 체크리스트 선택 시 제목은 `녹음 제목_후속 업무 체크리스트` 형식을 사용한다.
- 새 노트 본문에는 선택한 템플릿의 Markdown 구조를 적용한다.
- 각 템플릿의 필드는 녹음 스크립트와 요약 내용을 기반으로 자동 채운다.
- 채울 내용이 없는 섹션은 생성하지 않고, 남은 섹션 번호를 다시 정렬한다.
- PC와 모바일 노트 화면 모두에서 동일한 추출 흐름을 제공한다.

## 이유
- 녹음 결과는 회의록이나 후속 업무 정리로 재사용되는 경우가 많으므로, 사용자가 복사·정리하지 않아도 노트로 전환할 수 있어야 한다.
- 빈 섹션을 생성하지 않아야 자동 생성 노트가 검토 가능한 결과물로 바로 활용된다.
- 템플릿별 Markdown 구조를 고정해야 생성된 노트가 기존 노트 편집 경험과 일관된다.

# Decisions

Sheetric의 확정된 제품 결정을 모아 두는 폴더입니다.

## 언제 여기에 넣나요?

아래처럼 팀이 방향을 확정했을 때만 넣습니다.

- 특정 기능을 제공하지 않기로 결정
- 특정 기능의 동작 방식을 확정
- 나중에 다시 같은 논쟁이 생기지 않도록 남겨야 하는 정책

예시:

- 폴더 공유 권한 전파
- AI 검색 권한과 출처 열람
- 공유 링크 별도 읽기 전용 URL
- 검색바 리스트 상단 이동

## 언제 넣지 않나요?

아래 내용은 아직 decision이 아닙니다.

- 회의 중 나온 아이디어
- 확정되지 않은 후보안
- 나중에 논의하기로 한 내용
- 단순 UI 수정 메모

이런 내용은 먼저 `meetings/`에 남깁니다.

## AI는 어떻게 사용하나요?

AI는 `/spec-flow`, `/project-flow`를 실행할 때 이 폴더를 먼저 봅니다.

요청 내용이 기존 decision과 충돌하면 AI는 바로 진행하지 않고 사용자에게 확인해야 합니다. 상태가 `대체됨` 또는 `삭제`인 문서는 현재 정책으로 취급하지 않고, 문서에 연결된 후속 decision과 최신 기능정의서를 확인합니다.

## 작성 규칙

- 제목만 봐도 내용을 알 수 있게 씁니다.
- 확정된 내용만 씁니다.
- 배경과 이유는 짧게 남깁니다.
- 관련 기능이나 화면이 있으면 함께 적습니다.
- 기존 결정을 바꾸려면 새 decision을 만들거나 기존 decision의 상태를 명확히 갱신합니다.

# 모바일 단일 노트 모드

## 상태
수정

## 날짜
2026-06-23

## 프로젝트
- Sheetric

## 결정
- 모바일에서는 탭바를 제공하지 않는다.
- 모바일에서는 한 번에 하나의 노트만 열 수 있다.
- 모바일에서는 탭 전환 기능을 제공하지 않는다.
- 모바일 테이블에서는 화면 공간 확보를 위해 체크박스 컬럼과 즐겨찾기 컬럼을 제거한다.
- 모바일에서 행 이동이 필요한 경우 hover 기반 버튼 대신 길게 누른 뒤 드래그하는 방식을 기준으로 한다.

## 이유
- 모바일 환경은 hover 인터랙션과 다중 탭 사용에 적합하지 않다.
- 좁은 화면에서는 제목 컬럼과 본문 확인 영역을 우선해야 한다.
- 노션과 유사하게 한 노트에 집중하는 흐름이 모바일 사용성에 더 적합하다.

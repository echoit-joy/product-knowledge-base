# Altio 녹음 요약 및 스크립트 편집

## 상태
추가

## 날짜
2026-09-10

## 프로젝트
- Sheetric

## 결정
- Altio 녹음으로 생성된 녹음 블록에서 요약 내용과 스크립트 내용을 사용자가 수정할 수 있게 한다.
- 사용자는 자동 생성된 요약이나 스크립트에 오탈자, 누락, 표현 오류가 있을 때 직접 내용을 보정할 수 있다.
- 요약과 스크립트의 텍스트 영역에서는 외부에서 복사한 텍스트를 Ctrl/Cmd+V로 붙여넣을 수 있다.
- 수정된 내용은 해당 녹음 블록의 현재 내용으로 저장되어 이후 다시 열람할 때 유지되어야 한다.

## 이유
- 녹음 요약과 스크립트는 음성 인식과 자동 요약 결과이므로 실제 발화나 사용자의 의도와 다를 수 있다.
- 사용자가 결과를 직접 보정할 수 있어야 회의록, 기록, 업무 공유 자료로 활용하기 쉽다.
- 자동 생성 결과를 다시 만들지 않아도 필요한 부분만 빠르게 고칠 수 있어야 한다.

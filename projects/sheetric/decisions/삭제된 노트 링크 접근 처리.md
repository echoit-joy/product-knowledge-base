# 삭제된 노트 링크 접근 처리

## 상태
추가

## 날짜
2026-06-16

## 프로젝트
- Sheetric

## 결정
- 휴지통 이동 또는 영구 삭제된 노트의 링크에 접근하면 삭제된 노트 안내 토스트를 노출한다.
- 로그인된 사용자는 안내 후 메인 페이지로 이동한다.
- 로그인하지 않은 사용자는 안내 후 로그인 페이지로 이동한다.
- 삭제된 노트 링크 접근은 정상 노트 접근 플로우와 분리하여 처리한다.

## 이유
- 삭제된 노트 링크는 더 이상 유효한 콘텐츠 접근 경로가 아니다.
- 로그인 상태에 따라 사용자가 이어서 취할 수 있는 다음 행동이 다르다.
- 삭제된 콘텐츠 접근을 명확히 차단해야 링크 공유 정책과 충돌하지 않는다.

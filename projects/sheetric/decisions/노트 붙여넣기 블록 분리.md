# 노트 붙여넣기 블록 분리

## 상태
수정

## 날짜
2026-06-29

## 프로젝트
- Sheetric

## 결정
- 외부 Markdown 콘텐츠를 Sheetric 노트에 붙여넣을 때 전체 내용을 하나의 블록에 넣지 않는다.
- 붙여넣은 콘텐츠는 문단, 제목, 목록, 표 등 구조에 맞춰 적절한 블록으로 분리한다.
- 붙여넣기 결과는 노트 내부에서 편집 가능한 블록 구조를 유지해야 한다.

## 이유
- 긴 Markdown 전체가 하나의 블록에 들어가면 이후 편집과 구조 조정이 어렵다.
- 원본 Markdown의 의미 구조를 블록으로 보존하면 노트 편집 경험이 자연스럽다.
- 붙여넣기 동작은 가져오기 기능처럼 사용되므로 사용자가 별도 정리를 하지 않아도 되는 결과를 제공해야 한다.

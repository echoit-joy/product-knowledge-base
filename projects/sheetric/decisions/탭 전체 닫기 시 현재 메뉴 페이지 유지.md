# 탭 전체 닫기 시 현재 메뉴 페이지 유지

## 상태
수정

## 날짜
2026-09-08

## 프로젝트
- Sheetric

## 결정
- 즐겨찾기·내 드라이브·공유 드라이브·휴지통 화면에서, 탭 리스트 팝오버의 [모두 닫기]를 클릭하거나 열려 있는 탭이 순차적으로 닫혀 0개가 되는 경우:
  - 현재 사용자가 특정 메뉴(즐겨찾기·내 드라이브·공유 드라이브·휴지통 등)에 위치해 있다면 메인 페이지로 이동하지 않고 해당 메뉴 페이지를 그대로 유지한다.
  - 선택된 메뉴가 없는 경우에만 메인 페이지(Home)로 이동한다.
- as-is 동작: 탭이 모두 닫히면 현재 위치한 메뉴와 관계없이 무조건 메인 페이지로 이동.
- 관련 기능: 기능정의_MainPage main_01_09(탭 닫기 X 버튼), main_01_24(탭 리스트 팝오버 — [모두 닫기] 버튼 추가)

## 이유
- 특정 메뉴 작업 중 노트 탭을 모두 닫았을 때 강제로 메인 페이지로 튕기면 작업 흐름이 끊긴다는 수정 요청에 따름.

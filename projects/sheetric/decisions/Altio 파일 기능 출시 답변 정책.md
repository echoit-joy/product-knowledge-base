# Altio 파일 기능 출시 답변 정책

## 상태
추가

## 날짜
2026-09-10

## 프로젝트
- Sheetric

## 결정
- Altio는 파일 기능이 출시된 현재 기준으로 파일 조회, 파일 위치 안내, 파일 미리보기 가능 여부를 답변한다.
- 파일 목록을 안내할 때 `아직 출시되지 않은 파일 기능`이라는 취지의 문구를 덧붙이지 않는다.
- 노트에 첨부된 파일의 위치를 묻는 경우 내 드라이브 최상위가 아니라 실제 첨부된 노트를 기준으로 안내한다.

## 이유
- 파일 기능이 현재 서비스 범위에 포함되었으므로 미출시 전제의 안내 문구는 사용자에게 잘못된 정보를 준다.
- 파일이 노트에 첨부된 경우 저장 위치와 사용 맥락이 내 드라이브 파일과 다르다.
- Altio의 답변은 현재 기능 범위와 실제 파일 위치를 기준으로 해야 한다.

# 모바일 휴지통 생성 버튼 미노출

## 상태
삭제

## 날짜
2026-07-20

## 프로젝트
- Sheetric

## 결정
- 모바일 휴지통 화면에서는 새 노트와 새 폴더를 생성하는 플로팅 버튼을 노출하지 않는다.
- 휴지통 화면에서는 복구, 삭제 등 휴지통 맥락에 맞는 동작만 제공한다.

## 이유
- 휴지통은 삭제된 항목을 확인하거나 처리하는 화면이므로 신규 생성 액션이 함께 노출되면 화면의 목적이 흐려진다.
- 모바일에서는 화면 공간이 제한적이므로 현재 화면 맥락과 무관한 생성 버튼은 제거하는 편이 명확하다.

# 소유권 이전 대기 중 대상자 삭제 시 요청 자동 취소

## 상태
추가

## 날짜
2026-09-07

## 프로젝트
- Sheetric

## 결정
- 소유권 이전 요청이 대기 중인 대상자를 "이전 요청 취소" 대신 더보기 메뉴의 [삭제](공유 해제)로 직접 제거해도, 대기 중이던 소유권 이전 요청은 함께 자동 취소된다.
- 이때 실제 소유권 변경은 발생하지 않으며 기존 소유자가 소유권을 그대로 유지한다.
- 삭제된(공유 해제된) 대상자가 이전에 받은 소유권 이전 요청 이메일의 링크로 다시 접근하면, 더 이상 해당 항목에 접근 권한이 없다는 오류 토스트가 노출된다.

## 이유
- `share_02_05`(더보기 메뉴 — 이전 요청 대기중 상태) 스펙상 대기중인 대상자도 일반 공유 대상과 동일하게 [삭제] 메뉴로 공유 해제할 수 있는데, 이 삭제가 `share_02_07`의 일반 공유 해제 정책(개인 태그·즐겨찾기·공유 드라이브 참조 즉시 삭제)을 그대로 따르는 것인지, 대기 중인 소유권 이전 요청까지 함께 정리되는지가 스펙에 명시돼 있지 않았다.
- 대상자가 공유 대상 리스트에서 완전히 제거된 이상 소유권 이전 요청만 별도로 살아있을 이유가 없으므로, 삭제 시 요청도 함께 자동 취소되는 것이 [소유권 이전 요청 취소 이메일 미발송](소유권%20이전%20요청%20취소%20이메일%20미발송.md)의 "요청 취소는 대기 상태만 해제하며 실제 권한 변경은 발생하지 않는다"는 원칙과 일치한다.
- 삭제된 대상자는 더 이상 공유 대상이 아니므로, 과거에 받은 이메일 링크로 재접근을 시도해도 일반적인 접근 권한 없음 처리를 따른다.

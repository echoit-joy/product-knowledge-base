# 폴더 공유 제외

## 상태
삭제

## 날짜
2026-06-26

## 프로젝트
- Sheetric

## 결정
- 폴더는 공유 대상에서 제외한다.
- 폴더 우클릭 또는 더보기 팝오버에는 공유 메뉴를 제공하지 않는다.
- 내 드라이브 폴더 트리에서 폴더를 우클릭할 경우 새 노트와 새 폴더 생성 메뉴만 제공한다.
- 테이블 또는 폴더 트리에서 폴더 공유 기능을 신규 spec 또는 QA 범위에 포함하지 않는다.

## 이유
- 현재 제품 정책에서 공유는 노트 중심으로 관리한다.
- 폴더 공유는 하위 항목 권한 전파와 충돌 처리가 필요한 별도 기능이다.
- 폴더 공유 메뉴를 남기면 실제 제공 범위를 넘어서는 동작으로 오해될 수 있다.

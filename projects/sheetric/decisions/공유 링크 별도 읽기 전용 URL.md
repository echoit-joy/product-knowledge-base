# 공유 링크 별도 읽기 전용 URL

## 상태
수정

## 날짜
2026-06-26

## 프로젝트
- Sheetric

## 결정
- 링크 공유로 생성되는 URL은 편집 모드 URL과 분리된 별도 share URL을 사용한다.
- share URL은 읽기 전용 페이지로 제공한다.
- 노트 작성자가 share URL로 접근해도 읽기 전용 단일 페이지로 표시한다.
- 노트 작성자가 아닌 사용자가 편집 모드 URL로 접근하면 잘못된 접근 토스트를 노출한다.
- 주소창의 편집 URL과 링크 공유 아이콘으로 복사되는 URL은 동일하지 않다.

## 이유
- 편집 URL을 그대로 공유하면 권한 경계가 불명확해진다.
- 공유 링크는 조회 목적의 진입점으로 분리해야 보안과 UX가 명확하다.
- 작성자와 외부 사용자가 같은 share URL에서 동일한 읽기 전용 경험을 갖는 편이 예측 가능하다.

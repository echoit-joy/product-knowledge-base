# 삭제 예정 공유 항목 사본 및 복구 정책

## 상태
추가

## 날짜
2026-09-01

## 프로젝트
- Sheetric

## 결정
- 원본 소유자가 공유 중인 폴더 또는 노트를 휴지통으로 이동하면 공유받은 사용자의 공유 드라이브에는 삭제 예정 상태로 노출한다.
- 공유받은 사용자가 `삭제 예정 안내` 모달의 `사본 만들기`를 통해 삭제 예정 폴더 또는 노트의 사본 생성에 성공하면 해당 사용자 공유 드라이브에서 원본 항목을 제거한다.
- 공유 드라이브의 우클릭 메뉴 `복사하기`를 통해 사본을 생성한 경우에는 해당 사용자 공유 드라이브에서 삭제 예정 원본 항목을 제거하지 않는다.
- 생성된 사본은 사용자의 내 드라이브에 독립된 항목으로 저장하며 원본의 공유 관계를 승계하지 않는다.
- 원본 소유자가 휴지통에서 항목을 복구하면 `삭제 예정 안내` 모달의 사본 생성으로 원본이 제거됐던 사용자의 공유 드라이브에도 원본 항목을 다시 노출한다.
- 원본이 영구 삭제되면 공유 드라이브에서 원본 항목을 제거하고 다시 노출하지 않는다.
- 공유 드라이브 테이블에서 삭제 예정 폴더를 더블클릭하면 폴더에 진입하지 않고 `삭제 예정 안내` 모달을 노출한다.
- 삭제 예정 폴더의 안내 모달은 Esc 키 또는 Backdrop 클릭으로 닫을 수 있다.

## 이유
- `삭제 예정 안내` 모달의 사본 생성은 사용자가 원본의 삭제 예정 상태를 인지한 후 보관을 완료하는 동작이므로 공유 드라이브에서 원본을 제거하는 것이 자연스럽다.
- 우클릭 메뉴 `복사하기`는 사용자가 원본의 삭제 예정 상태를 인지하지 못한 상태에서도 실행할 수 있으므로, 사본 생성과 동시에 원본을 제거하면 항목이 갑자기 사라진 것으로 오인할 수 있다.
- 사본과 원본의 생명주기를 분리하면서도 소유자가 원본을 복구한 경우 기존 공유 관계를 다시 사용할 수 있어야 한다.
- 삭제 예정 폴더에 진입할 수 없는 상태에서도 사용자가 안내 모달을 명시적으로 닫고 다른 작업을 계속할 수 있어야 한다.

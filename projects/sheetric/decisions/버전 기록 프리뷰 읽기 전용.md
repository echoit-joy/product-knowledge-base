# 버전 기록 프리뷰 읽기 전용

## 상태
수정

## 날짜
2026-06-04

## 프로젝트
- Sheetric

## 결정
- 버전 기록 항목을 클릭하면 현재 문서 탭을 덮어쓰지 않고 새 탭에서 해당 시점의 노트 상태를 연다.
- 버전 기록 프리뷰 탭은 읽기 전용 화면으로 제공한다.
- 프리뷰 탭에서는 문서 수정, 버전 저장, 공유, 즐겨찾기, 더보기 액션을 제공하지 않는다.
- 프리뷰 탭에서는 텍스트 선택과 복사만 허용한다.
- 버전 기록 사이드바는 원본 문서 탭에서만 제공한다.
- MVP 범위에서는 버전 간 Diff 비교, 특정 버전 복원, 버전별 독립 파일 생성 기능을 제공하지 않는다.

## 이유
- 이전 버전 확인은 현재 문서를 변경하지 않는 조회 목적이므로 원본 문서를 덮어쓰지 않아야 한다.
- 복원과 Diff 기능은 별도 정책과 구현 범위가 필요한 기능이므로 MVP 범위에서 제외한다.
- 사용자가 이전 버전 일부를 활용해야 할 경우 프리뷰 탭에서 복사해 원본 문서에 붙여넣는 흐름으로 충분하다.

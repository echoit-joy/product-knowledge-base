# 노트 블록 전환 메뉴

## 상태
추가

## 날짜
2026-07-10

## 프로젝트
- Sheetric

## 결정
- 노트에서 6dot 아이콘을 클릭했을 때 노출되는 블록 팝오버 최상단에 `전환` 항목을 제공한다.
- `전환` 항목에 hover하면 제목1, 제목2, 제목3 등 블록 형식 전환 항목으로 구성된 하위 팝오버를 노출한다.
- 전환 메뉴의 세부 구성과 시각 디자인은 Figma 기준을 따른다.

## 이유
- 사용자가 기존 블록을 다시 작성하지 않고 원하는 텍스트/블록 형식으로 빠르게 바꿀 수 있어야 한다.
- 블록 단위 편집 기능은 노트 작성 흐름에서 반복적으로 사용되므로 상위 팝오버에서 바로 접근 가능해야 한다.

## 관련 화면
- 노트
- 6dot 블록 팝오버
